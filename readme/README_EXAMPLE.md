# FocusFlow

A small command-line task tracker for practicing Python fundamentals.

## Overview

FocusFlow is a sample project that stores simple tasks in memory while the program runs. It is a learning example, not a production task-management system.

## Features

- Add a task
- List current tasks
- Mark a task complete
- Practice functions, lists, and input validation

## Requirements

- Python 3.10 or newer

## Run

```bash
python main.py
```

Example interaction (illustrative):

```text
1. Add task
2. List tasks
3. Complete task
4. Exit
Choose an option:
```
