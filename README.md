# TechnicalBharat GitHub Starter Kit

A practical, beginner-friendly collection of templates to help developers create polished GitHub profiles and maintain professional repositories.

## What's included

- `profile/PROFILE_README_TEMPLATE.md` — customizable GitHub profile README
- `readme/PROJECT_README_TEMPLATE.md` — reusable project README
- `readme/README_EXAMPLE.md` — filled-in example for a sample project
- `.github/ISSUE_TEMPLATE/bug_report.yml` — structured bug report form
- `.github/ISSUE_TEMPLATE/feature_request.yml` — feature request form
- `.github/PULL_REQUEST_TEMPLATE.md` — pull request checklist
- `CONTRIBUTING.md` — contribution guidelines
- `CODE_OF_CONDUCT.md` — community conduct expectations
- `SECURITY.md` — responsible vulnerability reporting template
- `LICENSE-MIT-TEMPLATE.txt` — MIT license placeholder; replace the year and copyright holder
- `CUSTOMIZATION_CHECKLIST.md` — steps to adapt the kit to your project

## Quick start

1. Download or clone this folder.
2. Copy the files you need into your repository.
3. Replace every `[PLACEHOLDER]` with your project details.
4. Remove sections that do not apply to your project.
5. Review the license and community policies before publishing.
6. Commit the files to your repository.

## Add templates to a repository

GitHub recognizes issue forms in `.github/ISSUE_TEMPLATE/`, a pull request template at `.github/PULL_REQUEST_TEMPLATE.md`, and contribution guidance in `CONTRIBUTING.md`.

For a profile README, create a public repository whose name exactly matches your GitHub username and put the profile template in its root `README.md`.

## Important

These are general-purpose templates, not legal advice. Adapt them to your project, and do not claim security policies, support guarantees, or licenses you cannot actually maintain.

Created by TechnicalBharat for developers who want a clearer starting point for open-source work.
