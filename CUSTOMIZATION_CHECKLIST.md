# Customization checklist

Use this checklist before publishing the templates.

## General

- [ ] Replace all `[PLACEHOLDER]` text.
- [ ] Remove sections that do not apply.
- [ ] Check every URL and command.
- [ ] Use consistent project and organization names.
- [ ] Confirm the files reflect your actual workflow.

## GitHub profile README

- [ ] Repository name exactly matches your GitHub username.
- [ ] Repository is public.
- [ ] Profile claims and skills are accurate.
- [ ] Featured project links work.

## Project README

- [ ] Installation instructions have been tested from a clean environment.
- [ ] Usage example works.
- [ ] Requirements and supported versions are accurate.
- [ ] Screenshots and badges are real, not placeholders.
- [ ] License section matches the actual LICENSE file.

## Community files

- [ ] Issue labels exist or are created.
- [ ] Contribution instructions match the project's workflow.
- [ ] Code of Conduct includes a monitored reporting contact.
- [ ] Security policy has a private reporting route before publication.
- [ ] Pull request checklist matches maintainer expectations.

## License

- [ ] Chosen license is intentional.
- [ ] Copyright holder and year are correct.
- [ ] You have authority to license the included content.
